# セナ sprite-gen v1 試作

- sprite-gen v2.0.3 / provider=codex / ChatGPT認証。画像モデル版の指定なし。
- 参照: 既存セナ立ち絵→今回のbase.png→各行。各行にprepareが出力した配置ガイドを添付。
- 基準画像: 全身・右向き・紺のボブ・胸の留め具2個・記録板を確認。設定の5頭身より縦長なため、比率は今後の改善点。
- 192×256セル、論理高さ128、palette_size=24を指定。最終アトラスの可視色は44色（設定値を実測色数とは扱わない）。
- extract / compose-atlas: ok=true、各4コマ。透過画素290048、可視マゼンタ画素0。
- 原画の格子検出でpitch disagreementとphysical capの警告。整数2倍の出力には整形できたが、基準画像から一貫した格子を保証できたとは言わない。

## 動作の判定

|状態|判定|観察|
|---|---|---|
|idle|best-effort|全身と服を維持。小さな揺れはあるが、瞬きは不明瞭。コマ間で輪郭が若干変化し、末尾から先頭も完全一致ではない。|
|victory|best-effort|視線を上げて小さく拳を上げる流れを確認。手足の増殖・欠けは見られないが、服と輪郭に小さな揺れが残る。最後で止めるワンショット。|

連続コマ画像とcurationの再生表示で確認。galleryには比較試作として登録し、採用設定は変更していない。最終画像はsprite-sheet-alpha.png、切り出し矩形はmanifest.jsonのframe_layoutを使用。
