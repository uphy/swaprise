# セナの画像制作 v1

内蔵gpt-imageで立ち絵、顔アイコン、7種類のアニメーション（計60コマ）を生成。人物設定から立ち絵を作り、残り8種類は立ち絵を参照した。実際のプロンプトは各版の `.prompt.txt` に保存した。

全9画像がRGBA。生成されたアルファを保持し、画像の加工は行っていない。可視画素（alpha > 32）のうち R > 150、B > 120、G < R × 0.55、G < B × 0.55 のマゼンタ寄りの画素は全画像で0。数値は `pixel-v1-alpha-check.json` を参照。

コマ間の空白で行境界を計測し、足元18pxから横基準点と床位置を設定。素材内の倍率は共通。ブラウザで白・紺背景、先頭・途中・最終コマを確認し、市松模様の焼き込み、マゼンタの縁、隣接コマの混入がないことを確認した。生成画像のため表情や衣装の細部にはコマ間の差がある。

勝利の初回生成では余計な本が追加されたため使用せず、腰の記録板を触らない指示で再生成した。市松模様が焼き込まれた中間生成も登録しなかった。

`node tools/character-assets.mjs --check` 成功。`node --test tools/character-assets.test.mjs` は5件成功。画廊へ試作として登録し、採用設定は未指定。`review-v1.html` で全9種類を一覧再生できる。
