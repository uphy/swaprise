# メニュー曲の設計

メニュー（オープニングの後、モードを選ぶ画面）の曲を作り直すための設計。結論は「今の曲と同じ明るさのまま、主題をオープニングと同じ昇る分散和音にし、後半に息継ぎを入れた 16 小節の曲（候補 7）」を第一候補にし、方向の違う候補 8・9 と聞き比べて決める。候補は `tools/bgm-candidates.html` の 7〜9 で試聴できる（数字キーで再生、Esc で停止）。

## 今の曲

`src/render/bgm.ts` の `buildMenuSong`。試聴ページの「1. ポップ・フェアリー」を移したもの。

| 項目 | 値 |
|---|---|
| 調・テンポ | C major / 132 BPM |
| 長さ | 8 小節。1 周 14.5 秒 |
| ベース | 三角波の跳ねるライン（8 分で根音・オクターブ・5 度） |
| アルペジオ | 25% パルスの 16 分。8 小節ずっと鳴り続ける |
| 旋律 | 矩形波にビブラート。8 分の順次進行が主で、4 分の伸ばしが混ざる |
| ドラム | キック・スネア・ハイハットが 8 小節同じ |

音の作り（SFC 風の合成・エコー）は狙いどおりで、変える必要はない。足りないのは曲としての骨組み。

- 1 周が 14.5 秒で、メニューに 1 分いると 4 回聞く。記録や設定を開いている間も鳴るので、繰り返しが目立つ
- 16 分のアルペジオと旋律が最初から最後まで同じ密度で鳴り、盛り上がりも休みもない
- 旋律に「この曲」と分かる形（フック）がない。順次進行の 8 分が続くだけで、口ずさめない
- オープニングの最後（閃光で C のハープが駆け上がり、曲の 1 拍目が重なる）から続くのに、曲の頭がその一撃を受けていない

## メニュー曲に求めること

メニューはタイトル画面を兼ねる。ゲームを開くたびに最初に聞く曲で、しかも滞在時間が長い。

1. **タイトルの顔になる**。最初の 2 小節で「この曲」と分かる主題を出す。オープニングの閃光の一撃（c-e-g-c の駆け上がり）を受けて始まる
2. **長く聞けて飽きない**。1 周 25〜30 秒以上。密度の違う部分（A: 主題、B: 息継ぎ）を持ち、B で刻みを止めて空間を作る
3. **今の明るさを保つ**。1〜5 の候補から明るい「ポップ・フェアリー」を選んだ経緯があるので、暗くしない・遅くしすぎない
4. **ゲーム曲へ自然に渡す**。ゲーム曲（D major 96 BPM のチル）とは対照的なままでよい。カウントダウンで曲が止まるので、つながりは気にしなくてよい
5. **今の仕組みで鳴らせる**。`bgm.ts` のシーケンサ（16 分単位の音符列、楽器は ADSR＋ローパス＋エコー、ドラムはキック・スネア・ハイハット）で書ける形にする。新しい楽器を足すなら試聴ページの `INST` に同じ定義を置く

## 共通の仕様

| 項目 | 決め |
|---|---|
| 調 | C major。オープニングの一撃（`titleSting`: C のハープと C の和音）と同じ調で、曲の 1 拍目が閃光に重なる |
| 構成 | 16 小節 = A（8 小節・主題）＋ B（8 小節・息継ぎ）。A に戻るところで盛り上がる |
| 冒頭 | 1 小節目の頭に主題の最初の音を置く。イントロは付けない（閃光と同時に始まるため） |
| B の作り | 16 分の刻みを止め、8 分のハープかパッドで支え、旋律は長い音で歌う。ドラムは間引く |
| 楽器 | 試聴ページの `INST` にあるものだけ。ハープ・フルート・パッド・スタブ・クラビは 3〜5 の候補で使ったもの |
| ドラム | `parseDrum` の列を 16 小節ぶん並べて、A と B で変える（`bgm.ts` でも同じ書き方ができる） |

## 候補

### 7. せり上がりのテーマ（推奨）

今の曲の置き換えとして最も安全な案。明るさ・テンポ・楽器は今のまま、骨組みだけを入れ替える。

- 主題は「下から上へ昇る分散和音」。c5-e5-g5-c6 と上がって g5-e5 と降りる 1 小節の形を、Em・Am と根音を変えて繰り返す。せり上がる盤面と、オープニングの一撃（c-e-g-c）を受ける
- 進行は A: C-Em-Am-F-C-G-F-G、B: Am-F-C-G-Am-F-G-G。今の曲の C-G-Am-F を残しつつ、Em で色を足す
- A は今と同じ跳ねるベース・16 分のアルペジオ・矩形波の旋律。B は柔らかいベースとハープの 8 分、パッド、フルートに替え、ドラムはキックを半分に、ハイハットを裏拍だけにする
- B の最後の小節は g-a-b-c-d と駆け上がって A の頭の c に戻る
- 1 周 29 秒

### 8. 継ぎ市の朝（6/8）

世界観（段々の街、朝の市場と工房、手仕事）に寄せた案。滞在が長くても疲れない方向。

- 6/8 の揺れ。ハープの 8 分の分散和音の上を、フルートが素朴な節で歌う。刻みは 2・3 拍目の和音だけで、キックとリムしか叩かない
- 進行は C-Am-F-G-C-Em-F-G / Am-F-C-G-Dm-F-G-C。Dm で少しだけ翳りを入れて C で戻る
- 1 周 21 秒だが密度が低いので、繰り返しは目立ちにくい
- 今の曲から雰囲気が変わる。オープニングの一撃（4 拍子の頭）から 6/8 に入るので、閃光の直後だけ拍の感じが切り替わる

### 9. 跳ねる工房（シャッフル）

ノリで押す案。対戦を主に遊ぶ人向けの入口にしたいときの選択肢。

- 16 分をスウィングさせた跳ねるベース（シンコペーション）とカッティング風の和音スタブ。A はクラビ風の短い旋律、B はデチューンのパルスで歌わせる
- 進行は C-C-F-G-C-Am-F-G / Am-Em-F-C-Am-Em-F-G
- 1 周 31 秒
- 今の曲より「ゲーム機のサウンド」寄りになる。テンポは少し落ち（124 BPM）、跳ねで速く聞こえる

## 試聴と決め方

`tools/bgm-candidates.html` をブラウザで開き、1（今の曲）と 7〜9 を聞き比べる。見る観点は次の 4 つ。

1. 閃光の一撃から始まったつもりで 1 小節目を聞く。頭で「始まった」と分かるか
2. 2 周（1 分）続けて聞く。B に入ったときに息がつけるか、A に戻ったときに嬉しいか
3. 設定や記録を開いている場面を想像して、邪魔にならないか
4. ゲームの効果音（`tools/sfx-candidates.html`）と並べて、音色が浮かないか

作った側が音を聞けないので、和声は機械的に確かめてある（強拍の音が和音の構成音であること、全音が C major の音であること、小節の長さ）。音色のバランス（ゲイン）は候補 1〜5 と同じ楽器定義なので大きくは外れないはずだが、旋律の歌い回しは耳で直す前提。気になる小節を番号で指してもらえれば、その場で書き直す。

## 採用後の作業

1. `bgm.ts` の `buildMenuSong` を選んだ候補に置き換える。楽器は試聴ページの `INST` の値をそのまま `Instrument` に写す。候補 8 の `rim` は `DrumKind` にないので、`playDrum` に試聴ページと同じ定義を足す
2. `tools/bgm-candidates.html` の「6. 現行（比較用）」は古いゲームの曲なので、選んだ候補を「現行」に置き換えるか、6 を消す
3. オープニングの一撃（`titleSting`）は C major のまま。候補 8 を選ぶなら、閃光から 6/8 に入る感じを実機で確かめ、必要なら一撃の和音を 6/8 の頭に合わせて短くする
4. `e2e/bgm.spec.ts` と `e2e/opening-autoplay.spec.ts` は曲名（`"menu"`）と step の進み方を見ているだけなので、テンポが変わっても `opening-autoplay.spec.ts` の step のしきい値（16 分音符の数）だけ確かめる
5. README の「曲は `src/render/bgm.ts` にコードで書き」の段落に、選んだ曲の名前と調・テンポを書く
