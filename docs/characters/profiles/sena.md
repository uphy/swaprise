# セナ — 正しいやり方を覚え、新しいやり方も欲しくなる候補生

[設定資料の入口](../README.md)／[関係と秘密](../relationships.md)／[画像制作](../visual-guide.md)

識別子：`sena`。年齢は物語開始時のもの。「作者用の秘密」は人物紹介画面には載せません。


人間の女の子、18歳。通常キャラクターでニカのライバル。調整士の採用試験を控えています。イゼルの姪ですが、採用は別の試験官が判定します。

## 形と衣装

168cm、直線的な姿勢。青みの強い黒髪を顎の位置で切り揃え、左側だけ耳にかけます。切れ長の灰色の目、薄い眉。帽子や大きな髪飾りは付けません。

薄い石灰色の立ち襟上着、深い青の幅広ズボン、低い革靴。胸元に短い真鍮の留め具が二本並び、右腰に薄い記録板を差します。上着は前を真っすぐ閉じ、肩飾りや軍章を増やしません。

机の端と道具を平行に揃えます。焦ると上着の留め具に触れます。勝利しても一度盤面を確認し、それから小さく拳を握ります。負けた直後は無言で、時間差で悔しさが顔に出ます。

## 性格の両面

慎重な準備で、人を安心させるのが得意です。知ったことを説明するのも好きですが、訂正から会話に入るため、説教と受け取られます。規則を守ることと、今のやり方が正しいことを混同しがちです。

叔母に似ていると言われると誇らしい一方、身内だから選ばれたと思われるのを恐れています。ニカには対等な競争相手でいてほしいので、軽く負けを譲られると本気で怒ります。

## 個人的な楽しみと作者用の秘密

古道具屋で小さな舞台の背景板を集めています。人形劇の大げさな悪役台詞を覚えており、一人だと声色まで真似します。精密な作業の休憩に、わざと非現実的な世界を楽しんでいます。

半年前から固定計画の検討会に見学参加していました。問題に気づいていたのに、人前で意見を言わなかったことを恥じています。裏切り者だったことにはしません。公開できる議事録を自分で持参し、自分の判断の遅さも説明します。

一人称は「私」。丁寧でも過度なお嬢様言葉は使いません。ニカ相手では語尾が短くなります。

- 普段：「それで動くのね。……手順を、もう一度見せて」
- 開始：「準備できたわ」
- 連鎖：「ここまで読んでいるの」
- ピンチ：「順番を変えます」
- 勝利：「今度は、あなたの得意な配置で」
- 敗北：「悔しい。説明は少し待って」

ユノの未完成の地図を、最初に「未調査の場所が明記されているから使える」と評価できます。成長後も几帳面さは残します。対戦では準備から長い連鎖を組む印象です。
