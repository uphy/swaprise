# ロッカ — 人に休めと言い、自分は作業台に戻る整備士

[設定資料の入口](../README.md)／[関係と秘密](../relationships.md)／[画像制作](../visual-guide.md)

識別子：`rocca`。年齢は物語開始時のもの。「作者用の秘密」は人物紹介画面には載せません。


人間の女性、23歳。通常キャラクター。ニカが通う工房の先輩職人。師匠は健在ですが遠方の設備改修に出ていて、現在の工房はロッカが取り仕切ります。

## 外見と身体の使い方

176cm、幅のある肩と太い前腕。淡い砂色の髪を極端に短く刈り、頭頂だけ柔らかく残しています。濃い褐色の肌に、明るい茶の目。にっこり笑うと目が細くなります。

葡萄色の厚手の作業つなぎに、腰までの生成りの帆布前掛け。膝には四角い補強布。広い底の安全靴を履き、左腰から短い点検用ハンマーを下げます。工具は職人用の現実的な大きさにします。

足を開いて立ち、笑うと肩が大きく揺れます。小さな部品を拾うときは指先だけを慎重に動かします。勝つと腕を組み、満足げにうなずきます。負けるとその場でしゃがみ、盤面を下から見直します。

## 気質と成長

できること、できないことを早く判断します。危ない提案を止める役ですが、説明を省いて「駄目」と言い、若い二人に反発されます。本人は仕事を分けると相手に負担を押し付ける気がして、抱え込みます。

工房を師匠不在でも回せるようにしたい。最初は自分の技量を上げれば済むと思っています。終盤で、一人では確認できない数の設備に直面し、セナの記録とニカの観察を頼ります。点検の一部は同僚の整備士に任せ、報告を受けて次の仕事へ進みます。自分で全てをやり直すことをやめ、担当ごとの持ち時間と休憩を確保します。

## 私生活と秘密

小さな焼き菓子を作り、箱にきっちり詰めるのが趣味です。割れた菓子は自分で食べるため、皆から味見係を申し出られます。夜更かしして焼くと翌朝眠い、という普通の失敗もさせます。

ニカの独立用に中古工具を一組取り置いています。まだ渡さない理由は引き留めたいから半分、安全な作業判断を覚えてほしいから半分。ミトには「箱、いつまで隠すの」と見抜かれています。

- 普段：「止める理由から話すか。ここ、触ってみな」
- 開始：「よし、点検開始」
- 連鎖：「下からいくよ！」
- ピンチ：「まだ支えられる」
- 勝利：「動きは上々」
- 敗北：「今日はあんたの勝ちだ」

一人称は「あたし」。低く通る声で、決していつも怒鳴りません。イゼルの安全へのこだわりは理解しています。対戦では高く積まれても崩す順序を見失わない、粘りの印象を持たせます。
