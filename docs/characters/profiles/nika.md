# ニカ — 直すのが好きで、手放すのが苦手な修理屋

[設定資料の入口](../README.md)／[関係と秘密](../relationships.md)／[画像制作](../visual-guide.md)

識別子：`nika`。年齢は物語開始時のもの。「作者用の秘密」は人物紹介画面には載せません。


人間の女の子、16歳。通常キャラクターで主人公。下段の工房に通う見習いで、家族と市場の上の住居で暮らしています。特別な血筋や選ばれた力は持ちません。

## 見た目と動き

身長154cm、細身で肩と手がよく動きます。赤茶の短い巻き毛は耳の下で跳ね、前髪を右側の平たい留め金で押さえます。眉が太めで、考えたことが顔に出ます。蜂蜜色の目、そばかすのある温かな褐色の肌。

生成りの七分袖、焦げ橙の短い作業ベスト、紺の膝下丈ズボン、足首までの靴。腰の左側に、片隅を青い糸で直した四角い工具袋があります。主な持ち物は折り畳み定規。杖のように振り回さず、開いて長さを測り、閉じて考え込みます。

立つときは少し前のめり。話を聞きながら小さな部品を指で回します。勝つと両手を上げかけ、袋から工具が落ちそうになって押さえます。負けると頬を膨らませてから、失敗した箇所を覗き込みます。

## 本人が欲しいものと、つまずく理由

自分の看板を出して仕事を受けたいと思っています。壊れた物から使い道を見つけるのが得意で、人の失敗にも寛容です。ただし、頼まれていない箇所まで直してしまいます。「前のままがよかった」と言われる理由が、最初は分かりません。

頼みを断ると腕を疑われる気がして、納期を詰め込みます。仕事を人に任せることも苦手。成長は、ヌイの希望を聞き、使える古い縫い目を残してほつれだけ直す選択で示します。自分の技量を見せるために、依頼の範囲を広げる癖を改めます。工房の仕事を一件ロッカへ戻し、納期を守れる量だけ引き受けることも覚えます。

## 日常と声

- 好きなもの：焼いたパンの端、左右で形の違う取っ手、店を閉めたあとの作業台。
- 苦手なもの：乾くまで触れない接着剤、答えのない値段交渉、空腹のままの待ち時間。
- 癖：考えがまとまると「よし」を二度言います。道具の名前だけは妙に正確です。
- お金：新しい道具より、安い端材を買いすぎます。整理棚も自作しますが、棚が増え続けています。

一人称は「あたし」。説明するときは手が先に出ます。相手を励ますために、根拠のない成功を約束させないようにします。

- 普段：「ここ、持ってて。……ありがとう。もう離して平気」
- 開始：「どこからいこうかな」
- 連鎖：「つながった！」
- ピンチ：「待って、まだ触れる！」
- 勝利：「できた！　今の、もう一回見たい」
- 敗北：「あー……そこ、見てなかった」

## 関係・作者用の秘密・物語の種

ミトがずっと同じ街で働くと思っています。旅の話を聞いた直後は、寂しいと言うより先に「鞄、ほつれてるよ」と返します。セナの丁寧な仕事を堅苦しいとからかいますが、保証書の書き方はこっそり真似しています。

工房の名前を27個考えた小さな帳面があります。どれも看板に書いた瞬間に責任が生まれる気がして、決められません。ミトへの土産話の返事で、初めて一つの名前を使う短編にできます。

対戦の印象は、途中から別の手を見つけて立て直すタイプ。未熟さを毎回の失敗の原因にはせず、観察の鋭さでも場面を動かします。
