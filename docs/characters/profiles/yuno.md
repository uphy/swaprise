# ユノ — 歩くのが好きなのに、地図を人に渡すのは怖い地図職人

[設定資料の入口](../README.md)／[関係と秘密](../relationships.md)／[画像制作](../visual-guide.md)

識別子：`yuno`。年齢は物語開始時のもの。「作者用の秘密」は人物紹介画面には載せません。


人間の女性、20歳。通常キャラクター。3年前に別の街から移住し、店の案内図や散歩地図を作って暮らしています。

## 姿と道具

158cm、丸みのある頬と柔らかな体形。濃い栗色の髪を太い一本編みにして、背中の中央まで垂らします。目は暗い緑。表情は穏やかで、歩き始めると意外に足が速い人です。

苔色の腰丈ジャケット、薄桃のシャツ、茶のゆったりしたズボン。背中には平たい楕円形の地図筒。大きな帽子やマントは付けません。手には蛇腹折りの紙を持ち、余白に気づいたことを書き足します。

話している相手と周囲の道を交互に見ます。地図を広げると少し前が見えなくなります。喜ぶと地図を畳み忘れて抱え込み、落ち込むと端を丁寧に揃えます。

## 性格・望み・困りごと

初めて街に来た人の話を聞き、どこで、なぜ迷ったのかまで確かめます。地図の誤りを認めるのは早い反面、完全に確かめるまで出せず、必要な情報を手元に置いてしまいます。歩くのが難しい人、小さい人、大きい精霊では、同じ道が違って見えることを仕事の中心に置きます。

街の道を時間帯ごとに記した地図を出版したい。完成させてから見せる習慣を改め、「ここはまだ歩いていない」と書いた試作を住民に渡すことが成長です。

## 生活と裏設定

よその家の献立を当てるのが好きで、匂いのする時刻を余白に書きます。洗濯物の柔軟な揺れを見ると、しばらく立ち止まります。絵は上手いのに、人の似顔絵は全員丸顔になります。

以前の街で、雨天に通れない道を載せてしまい、客を遠回りさせました。誰かが亡くなった過去にはしません。その客から訂正を頼まれた経験が、必要以上の確認につながっています。

ピリカの情報は買い取り、公開範囲を話し合います。バロの記憶は好きですが、事実確認を遠慮しない関係へ進みます。ニカには説明図を頼まれ、代わりに地図筒の蓋を直してもらいます。

- 普段：「そこ、いつ歩いた道？　朝と夕方で違うかも」
- 開始：「ひとつずつ見ていこう」
- 連鎖：「あ、こっちへ続いてる」
- ピンチ：「戻れる場所は……あった」
- 勝利：「この順番、書いておこう」
- 敗北：「見えてない所があったね」

一人称は「わたし」。間を取りますが、常にぼんやりした声にはしません。対戦は盤面の広い範囲を見て、別の消し口へ切り替える印象です。
