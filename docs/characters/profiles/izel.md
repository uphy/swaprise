# イゼル — 街を止める決断はできても、人に任せる決断が難しい責任者

[設定資料の入口](../README.md)／[関係と秘密](../relationships.md)／[画像制作](../visual-guide.md)

識別子：`izel`。年齢は物語開始時のもの。「作者用の秘密」は人物紹介画面には載せません。


人間の女性、34歳。ラスボス。継ぎ市の運行責任者で、セナの叔母。権力を世襲する立場ではなく、調整士と現場担当を経て選任されました。

## 威厳を服と姿勢で作る

173cm、長い胴と落ち着いた立ち姿。灰褐色の髪を、うなじの低い位置で横長に折り畳んで留めています。分け目は右寄り。目は暗い琥珀色で、目の下に薄い疲れがあります。老女や少女には描きません。

炭色の膝下丈の上着に、内側から淡い青灰の服が見えます。上着は肩を広げず、裾がまっすぐ落ちる形。襟元には赤銅の四角い留め具が一つ。冠、翼、豪華な宝石、玉座は使いません。手には二つ折りの運行板を持ちます。

相手を見て話し、聞くときは運行板を閉じます。ただし、反論に困ると再び開いて数字を読みます。勝つと深く息を吐き、負けると椅子を引いて「座って」と会話を始めます。

## 強みと欠点

誰かが決めなければならない局面で、決断できます。嫌われる役目も引き受けるため、住民の評価には賛否があります。人を軽視したいわけではありませんが、事故を防ぐ数字の中に、店を畳む負担や小さな住人の遠回りを含められていません。

8年前の救援の遅れを、自分の判断が足りなかった経験として覚えています。それ以来、任せた先で起きたことも自分が全て把握すべきだと考え、休みを減らしました。本人が有能であるほど、部下も任せてしまいます。

## 作者用の秘密と私生活

固定計画の前に整備員の増員を求めましたが、街の予算では全希望が通りませんでした。本人は実現できなかった案を語るのは言い訳だと考え、住民には伝えていません。共同修理案を話し合う場で、確保できる人数と予算を住民に伝えます。

遠方の友人から絵葉書が届きます。窓辺に置くと旅行へ行きたくなるので、机の引き出しにしまいます。硬い焼き菓子を熱い飲み物に浸すのが好きで、ロッカの菓子もそうして食べ、本人に驚かれます。

## セナとの距離と、最後の対戦

家ではセナの舞台趣味を知っていますが、職場で話題にしません。セナは隠せているつもりです。叔母としてはセナの失敗をかばいたくなりますが、職場の責任者として、候補生であるセナ本人に説明させます。二人の口調は似ていますが、セナのほうが感情の切り替えが速いです。

最後の対戦では、住民の共同案に最大負荷をかける側を担います。負けたあとも危険な道の閉鎖は主張します。安全試験の結果に加え、今の人数と予算で点検を続けられる街床と便数に絞った運行案を確認し、全面固定を撤回します。自分が不在でも現場の担当者が止められる条件を承認し、その判断を後から責めないと約束します。定期的な試運転は住民と続けます。

- 普段：「急いでいる理由を、先に聞かせて」
- 開始：「実際の負荷で、確かめます」
- 連鎖：「ここから増えます」
- ピンチ：「……立て直せます」
- 勝利：「今日は止めます。次の案を持ってきて」
- 敗北：「続けましょう。今度は、同じ側で」

一人称は「私」。短く明瞭な言葉を選び、演説や悪役笑いはしません。終幕では市場で休憩を取りますが、運行板を忘れられず持ってきています。
