# バロ — 売りたい話は多いが、売りたくない品もある古道具屋

[設定資料の入口](../README.md)／[関係と秘密](../relationships.md)／[画像制作](../visual-guide.md)

識別子：`baro`。年齢は物語開始時のもの。「作者用の秘密」は人物紹介画面には載せません。


言葉を話すアナグマ。人間なら40代ほどの自立した大人として描きます。通常キャラクター。店には動物用と人間用の二つのカウンターがあります。

## 動物としての姿

立った高さは92cm。胴が横に広く、脚は短い。灰褐色の毛、目の周りから鼻先へ伸びる濃い模様、丸く小さい耳。手足の指先に短い爪があります。尻尾は短く、長いふさふさの尾にはしません。

くすんだ赤の短いチョッキと、腹を覆う青灰の前掛け。人間用のズボンや靴は履きません。鼻先の小さな丸眼鏡は、必要なときだけ掛けます。基本立ち絵では眼鏡を掛け、前掛けのポケットから値札の束が出ています。

会話時は二本足、低い棚を探すときは四つ足。笑うと胸より腹が先に揺れます。勝利時は両前足を擦り合わせ、敗北時は眼鏡を外して拭きます。

## 商売と本音

品物の来歴を話すのが好きで、相手が聞く気なら何時間でも話します。値段には細かくても、貧しい人に粗悪品を押し付けません。相手が感心すると話を少し大きくする癖があります。

旧市場にあった店を、一日だけ再開したい。今の店にも満足していますが、昔の場所で客とお茶を飲みたいのです。再開に必要な品を売れずに保管しているため、店の奥が使えません。

## 小さな秘密と関係

ユノに聞かれた路地の名を思い出せず、「鈴裏通り」と作ってしまいました。訂正の機会を逃し、その名が地図の試作に載ります。本人が謝り、一緒に現地の人へ聞きに行く短編に使えます。

ヌイには店の棚を一段貸しています。家賃代わりの包装をしてもらっていますが、ヌイ本人に「労働の契約」だと説明していません。対等な取り決めをする余地があります。オルドとは旧市場時代からの顔見知りです。

硬い梨、昼寝、客が直した跡のある品が好き。新しい物を一律に嫌う人物にはしません。計算道具だけは最新式を買います。

- 普段：「その傷ね、使うぶんには困らんよ。値は下げるけど」
- 開始：「ひと勝負、どうだい」
- 連鎖：「まとめて持っていきな」
- ピンチ：「まだ奥にあるんだ」
- 勝利：「おや、いい手が残ってた」
- 敗北：「参った。これはおまけできんね」

一人称は「わし」。語尾の古さは控えめにします。対戦では消す場所を残しておき、大きくまとめる印象です。
