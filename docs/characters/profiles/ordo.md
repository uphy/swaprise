# オルド — 通すより、帰ってくる人を数えるのが好きな門の精霊

[設定資料の入口](../README.md)／[関係と秘密](../relationships.md)／[画像制作](../visual-guide.md)

識別子：`ordo`。年齢は物語開始時のもの。「作者用の秘密」は人物紹介画面には載せません。


意識を持って40年。中ボス。中央管理所へ通じる橋の入口に据えられた、安全門の精霊です。

## 人型にしない設計

高さ240cm、幅200cm。左右二本の陶製の太い支柱と、上をつなぐ弓形の梁で、一体の精霊です。中央は空洞で、人が通れます。支柱の外側に木の補強材、内側に真鍮の薄い表示板。顔・腕・脚・王冠は付けません。

全体は深い藍の釉薬、梁の中央に琥珀色の横長の採光部。左右の表示板の角度と、採光部の明るさで気分を示します。苔を全身に付けた遺跡にはせず、日々手入れされた設備として描きます。

その場から歩いて移動できません。表示板を回し、梁をわずかに傾けられます。声は陶器の胴に響きます。対戦の立ち絵も門のまま、盤面の横に縮小配置する想定です。

安全柵は一本の木製の遮断棒です。本人から見た左支柱の内側に真鍮の蝶番で取り付け、通常の立ち絵では通路を横切る水平位置に下ろします。通行を許可すると蝶番を軸に先端を上げ、左支柱の内側に沿って垂直に収めます。棒と蝶番は開放時にも見えます。

## 本人の論理と楽しみ

名前より、通った時刻と荷物の重さを覚えます。初対面には無愛想ですが、通行人が戻ると表示板を一枚鳴らします。人を守る仕事に誇りがあり、許可条件に書かれていない利用者は止めるのが親切だと思っています。

事故後、祭りの入場案内をしなくなりました。かつては客の人数を数えて景品を渡す役目もあり、その騒がしさが好きでした。バロが持つ古い入場券を見て、今年の祭りを完全に止めたくない気持ちを言葉にします。

## 関係と変化

ロッカが点検に来る前に、自分で届く蝶番だけ磨きます。ヌイが布の角を挟まないよう、何度も注意します。事故を防ごうとして、つい話が長くなります。ピリカを荷物と誤認したことがあり、正式に謝る場面を作ります。

通行条件を更新するには、運行責任者の承認と現場の検査が必要です。試合で負けた勢いだけで安全を無視しません。ニカたちの資料を受け取り、条件を満たした試運転を自分で確認して門を開けます。

- 普段：「帰りの時刻も、決めてあるか」
- 開始：「通行試験を始める」
- 連鎖：「荷重、移動」
- ピンチ：「支えを、組み直す」
- 勝利：「もう一度、準備して来なさい」
- 敗北：「確認した。通ってよい」

一人称は「私」。ゆっくりした大人の声。機械音声のような数値報告だけにはしません。勝利時は表示板が水平に揃い、敗北時は柵が上がります。対戦は大きな塊を段階的に処理させる印象です。
