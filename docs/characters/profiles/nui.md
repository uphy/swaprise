# ヌイ — 包むのは上手、返すときは少し寂しい布の精霊

[設定資料の入口](../README.md)／[関係と秘密](../relationships.md)／[画像制作](../visual-guide.md)

識別子：`nui`。年齢は物語開始時のもの。「作者用の秘密」は人物紹介画面には載せません。


意識を持って2年の精霊。通常キャラクター。元の布は何十年も市場で使われてきました。人間の幼児とは扱わず、得意分野と不慣れな分野の偏りが大きい住人として描きます。

## 体の決まり

高さ約60cm。中身のない灰藤色の大きな包み布が、空気を含んで立っています。布の中央をつまみ、白い短い紐で縛って上部に小さな結び目を作ります。布の四隅は結ばず、裾に残します。前面には二本の濃い縫い目があり、その傾きで表情を出します。丸い目玉、口、手足、人の体はありません。

下端の四隅で床に触れ、一隅ずつ送って歩きます。持ち上げるときは布の角を使います。右下に黄土色の長方形の継ぎ布があり、左上には古い白い縫い目が残ります。透ける幽霊状にはせず、布の重さと折れ目を描きます。

喜ぶとふくらみ、困ると結び目が少し緩みます。負けると平たくなりますが、破れたり消えたりしません。出入り口の狭い場所は畳んで通れますが、包んでいる荷物以上には小さくなれません。

## 望みと行き違い

相手の大切な物を預かると、信用されたと感じます。返すのを後回しにする癖があり、借りた物が増えています。物を隠す悪戯ではなく、「用が済んだら一緒にいる理由もなくなる」と思っているためです。

お金をためて、自分専用の道具を一つ買いたい。バロの店で働いた分を小さな端布で受け取り、自分で選んだ色を集めています。いま欲しい道具は、継ぎ布を整理する蓋付きの小箱です。返したあとにも遊びの約束をすることで、物を預からず人と会う楽しみを覚えます。

## 声・秘密・描写の注意

一人称は「ヌイ」。短い文で話し、包み方や布地の話になると急に詳しくなります。繰り返す語だけの赤ちゃん言葉にはしません。眠ると平たい四角になり、干されるのは好きですが、本人に断りなく洗われるのは嫌いです。

ニカにほつれを直してほしい一方、古い縫い目は残してほしい。全部新しくなると自分の使い心地が分からなくなる不安があります。これは世界の確定した危険ではなく、ヌイ本人の心配です。

- 普段：「包む？　今日は返すところまで、できる」
- 開始：「角から、そろえる」
- 連鎖：「ほどけた。もうひとつ」
- ピンチ：「まだ、たためる」
- 勝利：「きれいに、空いた」
- 敗北：「しわに、なった……」

オルドには用途以外の好きなことを質問します。先輩を崇拝するだけでなく、答えが長いと途中で平たくなって休みます。対戦は詰まった場所をほどいて連鎖へつなげる印象です。
