# ピリカ — 近道を売る、小柄で腕のいい案内業者

[設定資料の入口](../README.md)／[関係と秘密](../relationships.md)／[画像制作](../visual-guide.md)

識別子：`pirika`。年齢は物語開始時のもの。「作者用の秘密」は人物紹介画面には載せません。


言葉を話すトビネズミ。人間なら20代前半ほどの大人。性別は初期設定で固定しません。通常キャラクター。小型住民向けの案内と軽い荷物の運搬を請け負います。現在は市場の共同受付の一角を間借りし、持ち運べる札立てを出して営業しています。

## 輪郭と動き

耳を含む立ち姿で48cm、長い尾は全長の別枠です。砂色の毛に白い腹、大きな黒い目、細長い後ろ脚。尾の先には濃い茶の小さな毛束があります。耳は細く長く、足も尾も省略しません。

濃い青の胸当て型ハーネスに、黄色い小さな札入れを左右へ一つずつ。人間の服を縮めた全身衣装にはしません。前足で短い鉛筆を持ち、爪先で数字を示す癖があります。

止まっていても重心を少し上下させます。大きな身振りのあと、尾で姿勢を戻します。勝つと一度だけ跳ね、負けると耳が横へ開きます。マスコット的な赤ちゃん声にしません。

## 人柄と望み

話が早く、料金の説明も明快です。専門知識を「かわいいから教えて」で済まされるのが嫌い。自分の仕事を評価する相手には、次に困りそうなことまで教えます。

小さな住人が大声を出さずに注文できる、自分の案内所が欲しい。近道を公開すると商売がなくなると心配していますが、ユノと地図を作るうち、道の維持や更新にも仕事があると気づきます。

## 日常・裏設定・台詞

雨が苦手で、濡れた石の上では速さを出せません。晴れの日の強みが通用しない場面で、ミトと素直に分業できるかが見せ場です。炒った種を食べ比べ、店ごとに細かな順位を付けています。

人間サイズの窓口で、順番を三度飛ばされた日の札を持っています。悲しいお守りとして常に見せず、自分の案内所の受付番号を考えるときに出します。ミトの街外への希望は知っていますが、本人に代わってニカへ話しません。

- 普段：「近い道と、荷物が通る道。どっちが要る？」
- 開始：「速さだけじゃないよ」
- 連鎖：「はい、次の角！」
- ピンチ：「狭いけど、通れる」
- 勝利：「案内料はあとでね」
- 敗北：「うわ、その道あったか」

一人称は「自分」。説明は歯切れよく、照れると早口になります。対戦の印象は小さな隙間を拾う切り返し。小柄であることを、ずるさや臆病さには結び付けません。
