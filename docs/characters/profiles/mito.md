# ミト — 人の予定に詳しく、自分の予定を後回しにする配達員

[設定資料の入口](../README.md)／[関係と秘密](../relationships.md)／[画像制作](../visual-guide.md)

識別子：`mito`。年齢は物語開始時のもの。「作者用の秘密」は人物紹介画面には載せません。


人間の女の子、17歳。通常キャラクターでニカの親友。街内の定期便を請け負い、兄姉と共同で小さな配達所を使っています。

## 外見

162cm、長い脚とすっきりした体形。灰色がかった黒髪を、襟足の低い位置で小さく結びます。前髪は中央から左右に分かれ、額が見えます。濃い茶の目と、口角の片側だけが上がる笑い方。

青緑の膝丈コートは脇が深く割れ、下に灰白のシャツと細身のズボン。胸を横切る太い鞄のベルトと、肩のすぐ下に来る丸めた雨よけ布が目印です。翼、羽飾り、飛行靴は付けません。届け先の札を、丸い留め輪でまとめています。

相手の正面に立ち続けず、歩く方向を向いたまま話しがち。大切な話では鞄を下ろして座ります。勝利時は留め輪を一度回し、敗北時は額に当てて笑います。

## 性格と望み

人の事情をよく覚えているので、頼れる配達員です。「たぶんこうしてほしい」を先回りしすぎ、相手が望んでいない手助けもします。ニカの仕事を勝手に別日に移して怒られたことがあります。

街の外を巡る長距離便に応募したいと思っています。街が嫌いなわけではなく、手紙に出てくる場所を自分で見たいのです。目標は、誰かに必要とされながらでも、休みや旅立ちを自分で決めること。

## 暮らし・話し方・秘密

- 冷たい豆のスープと、知らない土地の絵葉書が好き。辛い料理は得意だと見栄を張ります。
- 休日も道の混み具合を数えてしまいます。贈り物を選ぶのは得意、受け取って喜ぶのは下手です。
- 一人称は「わたし」。軽い冗談を挟み、深刻な話ほど短くなります。
- ピリカとは料金を明確に分ける商売仲間。小柄だからと報酬を下げる相手には、はっきり反対します。

作者用の秘密は、長距離便の募集票を鞄の底に入れていること。まだ応募していません。ニカの許可を待つような態度をやめ、出発時期を自分で伝えるのが物語の一歩です。

- 普段：「急ぎ？　急ぎじゃないなら、座ってから聞く」
- 開始：「一便、付き合って」
- 連鎖：「次も来るよ」
- ピンチ：「寄り道はここまで」
- 勝利：「間に合った。お待たせ」
- 敗北：「あれ。見事に追い越された」

短編では、配達物のない一日を過ごさせます。誰も頼ってこない静けさに落ち着かず、最後に自分宛ての絵葉書を書きます。対戦の印象は小刻みに消し続ける、身軽な速攻型です。
