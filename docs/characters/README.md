# キャラクター設定 — 継ぎ市と10人の住人

swaprise の物語と画像制作に使う設定案です。昇降機で通りがつながる街「継ぎ市」を舞台に、修理屋見習いのニカと、仕事も体の形も違う住人たちを描きます。人間の女性6人、言葉を話す動物2体、人型でない精霊2体の計10体です。

現時点では企画案として保存し、ゲームの実装仕様とは分けて扱います。名前や年齢はこの案の中で統一し、後から変更するときは関係する資料も揃えます。

## 資料の構成

| ファイル | 記録する内容 |
|---|---|
| [world.md](world.md) | 街の仕組み、種族、パズルとの接点、創作上の約束 |
| [profiles/](#人物一覧) | 1人1ファイルの性格、外見、生活、台詞、秘密、成長 |
| [relationships.md](relationships.md) | 二人の関係と、開始時点で誰が秘密を知っているか |
| [story-seeds.md](story-seeds.md) | 事件の真相、時系列、本編9戦の案、日常の短編12案 |
| [visual-guide.md](visual-guide.md) | 共通の絵柄、体格の比較、画像生成用文章、表情差分 |

## 設定を更新するときの置き場所

人物本人に属する事実は `profiles/`、世界の仕組みは `world.md` を正本にします。二人の間に起きたことや互いの認識は `relationships.md` に記録します。事件の原因・発生順・各場面で明かす情報は `story-seeds.md` に置きます。

`visual-guide.md` の個別プロンプトは、各人物の外見から作った制作向けの要約です。外見を変更したら該当プロンプトと体格表も更新します。個人の秘密を変えた場合は、`relationships.md` の「秘密を誰が知っているか」も確認します。

人物ファイルの英字名は、将来画像と対応付けるための識別子です。表示名を変えても、識別子は原則そのままにします。新しいキャラを増やす際は、既存キャラとの関係を最低二つ加えます。

画像生成では、この資料の共通指定と対象人物のファイルを使います。脚本では登場人物のファイルに加えて、関係表と事件の時系列を使い、まだ知らない秘密を台詞に混ぜないようにします。
