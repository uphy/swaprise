# キャラクター画廊

[index.html](index.html)をブラウザで開くと、人物ごとの画像とアニメーションを確認できます。ローカルファイルでも開けるため、サーバーは不要です。

画像・プロンプト・制作途中のデータは`assets/characters/`に保存します。登録方法と定義の項目は[素材の保存と配信](../asset-management.md)を参照してください。

## 登録内容を更新する

1. 人物・動作・版に対応する`asset.json`を作成または更新します。
2. 新規版は`character.json`の`assets`へ追加します。
3. `pnpm assets`を実行します。
4. ブラウザを再読み込みし、画像・再生・リンクを確認します。

`catalog.js`は人物と素材、`actions.js`は動作の区分を表示する生成データです。直接編集せず、`assets/characters/`のJSONから生成します。生成した両ファイルはGitに含めます。

## バージョンと採用版

動作を選ぶと採用版を優先して表示します。採用未定の場合は`assets`に登録した先頭の版を表示します。「素材あり」は登録済みという意味で、採用済みとは限りません。

採用の正本は`assets/characters/<人物ID>/character.json`の`adoptedAssets`です。ユーザーの採用判断に合わせて更新し、同じ人物・同じ動作の素材IDを指定します。画廊で版を選び直しても採用指定は変わりません。

## 再生と確認

アニメーションは画像の読み込み完了後に自動再生します。一時停止・コマ送り・速度変更を使って動きを確認できます。速度変更はその場の表示だけに適用され、素材を選び直すと保存された`fps`に戻ります。

待機とピンチはループし、他の動作は最終コマで止まる設定を基本とします。登録済みのコマ座標、基準点、倍率を使い、元画像は書き換えません。明暗の背景と全コマ、開始・終了の姿勢を確認してください。

ゲームでは成功・着地の短い動作の後に待機かピンチへ戻します。画廊の最終コマ停止とは用途が異なります。

制作時は[生成方針](../generation-policy.md)と[character-artスキル](../../../.agents/skills/character-art/SKILL.md)を参照します。
