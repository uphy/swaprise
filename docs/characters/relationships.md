# 人物の関係と秘密を知る範囲

[設定資料の入口](README.md)

## 関係は互いの思い込みから動く

次の組み合わせを会話の基本にします。親しい相手でも、相手の望みを全部知っているわけではありません。

| 組み合わせ | 表向きの関係 | 片方だけが知っていること | 動く場面 |
|---|---|---|---|
| ニカ・ミト | 幼なじみ。修理と配達を頼み合う | ミトは街外の求人を持っている | ニカが旅用の鞄を直す |
| ニカ・セナ | 実地派と試験の優等生 | セナはニカの修理手順を写して練習している | 互いの得意な盤面を教え合う |
| ニカ・ロッカ | 見習いと先輩 | ロッカはニカの独立用工具を取り置いている | ニカが初めて仕事を断る |
| ニカ・ヌイ | 修理を頼まれた友達 | ヌイは古い縫い目を残してほしい | 良かれと思った交換をやり直す |
| ミト・ピリカ | 大荷物と狭い道で分業する商売仲間 | ピリカはミトの旅立ち後の仕事が心配 | 無料の試走が有料の契約になる |
| ミト・イゼル | 配達員と定期便の依頼主 | ミトはイゼルが届いた絵葉書を飾らないと知る | 外の街の話が仕事の話を越える |
| セナ・イゼル | 姪と叔母。職場では候補生と責任者 | セナは固定計画の検討を早くから知っていた | 会議で身内の案に異議を出す |
| セナ・ロッカ | 記録を確認する人と現場の人 | ロッカはセナの父にも技術を習った | 記録漏れの責任を押し付けず直す |
| セナ・バロ | 値切りが下手な常連客 | バロは彼女の舞台小物収集を知る | お堅い服装で人形劇の手伝いをする |
| ロッカ・イゼル | 修理の必要性は一致、止め方で対立 | イゼルは工房の追加予算を要求している | ロッカが安全上止めるべき道を認める |
| ロッカ・オルド | 点検係と頑固な設備精霊 | オルドは点検日に合わせて蝶番を磨く | ロッカが初めて点検を同僚に任せる |
| ユノ・ピリカ | 地図作りの協力者と情報提供者 | ユノは小柄な住人向けの別冊を作っている | 近道の対価と公開範囲を決める |
| ユノ・バロ | 昔の店名を聞きに来る客と語り手 | バロは覚えていない地名を一つ作ってしまった | 間違った地図を二人で直す |
| バロ・ヌイ | 店の居候と店主 | ヌイは仕事の報酬として端布を集めている | 初めて店に家賃を払おうとする |
| ピリカ・オルド | 通してほしい小動物と安全門 | オルドの古い規則に小型住民の欄がない | 小さな入口を正式に設ける |
| ヌイ・オルド | 若い精霊と先輩精霊 | オルドも修理前の形を恋しく思う | 用途以外の好きなことを聞く |
| ユノ・イゼル | 調査を求める職人と許可を出す人 | ユノは事故当時の街を見たことがない | 経験がない相手の測量を認める |

### 秘密を誰が知っているか

| 秘密 | 開始時に知る人物 | 明かすきっかけ |
|---|---|---|
| ミトが長距離便に応募したいこと | ミト、求人を運んだピリカ | 旅用鞄の修理 |
| ニカの工房名の候補帳 | ニカのみ | ミトが独立について尋ねる |
| ロッカが取り置くニカの独立用工具 | ロッカ、見抜いているミト | ロッカがニカに工具を渡す |
| セナの舞台趣味 | セナ、バロ、イゼル。セナはイゼルには知られていないと思っている | セナが人形劇の代役を引き受ける |
| セナの検討会への見学参加 | セナ、イゼル | 議事録を皆で読む |
| バロの作った地名 | バロのみ | ユノの現地調査と食い違う |
| オルドの昔の仕事に祭りの入場案内があったこと | オルド、バロ | 古い入場券が見つかる |
| 必要な人数まで増員できなかったこと | イゼル、管理所の職員 | 修理計画を共同で組む |

どの秘密も、相手が自発的に話すか、調査に必要な資料を一緒に確認して明かします。主人公が無断で日記を読む展開は基本にしません。
