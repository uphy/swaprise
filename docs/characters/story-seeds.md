# 本編の事件と短編の種

[設定資料の入口](README.md)

事件の真相と対戦順は、今後ストーリーを作るための案です。ここから脚本を起こす際は、人物の動機に合わせて変更できます。

## 事件は「明日の街が動かない」

年に一度の「橋替え祭」では、普段つながらない通りを一日だけ結びます。各店は共同で出し物を考え、住民は街中を巡ります。今年は祭りの前日に中央管理所が予定を取り消し、すべての街床を、橋が常につながる決まった高さに固定すると発表します。

主人公ニカの最初の目的は、閉鎖で届かなくなった交換部品を取ってくることです。祭りの準備も、自分の修理仕事も止まってしまいます。配達員ミトと出かけるうち、普段は便利なはずの時間割から、少しずつ取り残されている人に出会います。

最後の相手は街床の運行責任者イゼルです。壊れた設備を無理に動かさせないために、固定を選びました。ただし、移転を求められる店や、引っ越せない大型精霊の都合を十分に聞いていません。被害を防ぐ力がある一方で、自分の判断を覆す情報を受け入れにくくなっています。

本編の軸は、住民が使っている道を確かめ、修理できる範囲を示し、街を安全に動かす方法を皆で作ることです。大きな危機の合間にも、配達の寄り道、食べ物の好み、商売の張り合いを入れます。

### 作者用の真相

8年前、旧市場の街床が予定外の位置で止まり、橋を一つ壊しました。死亡者はいませんでしたが、住民の避難と店の休業が続きました。当時26歳の運行担当イゼルは、古い地図に載っていない手動の連絡路を把握できず、救援を遅らせました。

事故後は点検が厳しくなりました。一方、予算不足で古い連絡路の調査は後回しになり、地図には「閉鎖」とだけ記された場所が残りました。住民は生活のために一部を直して使い続けています。設備の老朽化に加え、公式の時間割と実際の利用状況のずれが、今年の不調を増やしています。

イゼルは設備の傷みを知っていますが、住民の修理で使える道が増えたことを知りません。住民の側も、中央が把握している亀裂や荷重の限界を知りません。ニカが全部を直す展開にはしません。ロッカが設備を検査し、ユノが地図を更新し、ミトとピリカが実際の所要時間を測る必要があります。

調整盤の対戦は、二つの盤で負荷をかけ合う試験としても使えます。実際の街床を動かす前に盤上で確かめるため、試合の負けが街の事故に直結することはありません。

精霊オルドは事故以前から存在する安全門です。現在も古い許可条件で動き、閉鎖された道の状態を調べに行く人まで止めています。終盤では、中央から届く運行記録と、住民が集めた実測を照合して、通行条件を更新します。

## 本編に育てられる対戦順

ニカを主人公にした場合の9戦の案です。各戦の前後には、対戦と別に、相手の困りごとを聞く短い場面を置きます。

1. ミトと部品の受け取り競争。操作に慣れながら、固定計画の知らせを聞きます。
2. ピリカが間借りしている市場の共同受付で通路調整を試す。小さな住民の道が地図にないと気づきます。
3. バロの店で古い調整盤を動かす。旧市場の道具と入場券が出てきます。
4. ヌイと荷物を仕分ける競技。借り物と返却先を整理し、古い連絡路の利用者を探します。試合後、ニカはヌイの希望を聞いて古い縫い目を残し、ほつれだけを直します。
5. ロッカの工房で実技試験。ニカの応急修理だけでは荷重に耐えられないことを確かめます。ロッカは点検の一部を同僚に任せ、報告を受けて修理の分担を決めます。
6. ユノと複数の道を順に試運転。使える道と、今回諦める道が分かれます。
7. セナと管理所への提案を実演。彼女は検討会に出ていたことを打ち明け、共同案の提出者になります。
8. オルドの通行試験。セナが中央との連絡役になり、イゼルから調査隊の通行試験の承認を得ます。ここまでの測量と修理記録を反映した条件で、中央へ通じる門を開けます。
9. イゼルと新しい時間割を試験運行。共同案は、既存の予算と担当人数で維持できる街床と便数に絞ります。対戦は最大負荷を再現する実演で、安全確認に加え、点検担当と運行を止める条件まで決めて合意します。

結末では全ての道を一度に復旧しません。今年の祭りは規模を縮め、修理した通りで開催します。残った工事や、街外へ行くミトの便りを、後の物語につなげます。イゼルは職を続け、住民との定期的な試運転を引き受けます。現場の担当者が、イゼルの不在時にも決めた条件に従って運行を止められるようにします。

### 勝敗だけで人格を変えない

仲間になる理由は、試合中に見えた工夫と、その前後の具体的な約束に置きます。負けたイゼルが急に陽気になる、ピリカが情報を全部無料で渡す、といった変化はさせません。悩みが残っていても、以前は選べなかった小さな行動を一つ選べれば成長になります。

再戦では事件の説明を繰り返さず、練習・休憩中の遊び・点検の手伝いとして会話を用意できます。ほかのキャラを主人公にする場合も、ニカの目的や台詞をそのまま移植せず、人物表の「いま欲しいもの」から導入を作ります。

## 日常の短編に使う12の種

- ニカが直した湯沸かし器は毎回違う音で鳴ります。ロッカは不具合だと言い、バロは高く買いたがります。
- ミトの休日の予定を、皆が善意で埋めてしまいます。本人が初めて「今日は配達しない」と言います。
- セナが人形劇の代役をします。客席のニカは、声だけで本人と気づきます。
- ピリカ用の受付台を作ったら、ヌイにも好評です。ロッカは二人の高さが違うことに困ります。
- ユノの地図に「昼寝によい場所」が書かれ、バロの秘密の椅子に行列ができます。
- ヌイが包んでくれた弁当は完璧ですが、開け方を教え忘れました。セナが規則正しく解こうとして苦戦します。
- オルドに祭りの招待状が届きます。動けない本人のために、出し物の巡回順を変えます。
- ロッカの小さな焼き菓子が評判になります。量産はしたくないので、レシピをユノに渡します。
- イゼルが私服で市場へ行くと、顔を知らないピリカに道案内を売り込まれます。
- バロの値札の付け間違いを、誰も得をせずに直すにはどうするかで、ミトとセナが言い争います。
- 雨で配達が止まった日、ピリカは体の小ささを生かせません。ミトに荷台を引いてもらい、料金を折半します。
- 帰ってきたミトが新しい店への道を知らず、ニカが初めて街を案内します。
