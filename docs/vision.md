# このゲームが目指すもの

機能の採否はここで決める。

連鎖が気持ちいい。それだけで成り立つパズルにする。

- 楽しさの中心は連鎖。揃った瞬間の閃き、積み上がる連鎖の音と揺れ、相手にどっさり降る板。演出と音はここに集める
- 遊ぶ相手は自分と友達。自己記録（エンドレス・タイムアタック）と対戦（同じ画面・オンライン）の 2 つを磨く。ストーリー、キャラクター、収集要素、レベル上げは持たない。連鎖の気持ちよさやピンチの緊張は、人物の反応ではなく盤面の効果と音で出す
- パズルモードは連鎖の練習。決まった手数で消す面を解くうちに、落として揃える・連鎖・同時消しの形が手に入り、対戦や記録に戻ったときに連鎖が組める
- ルールはこのジャンルの定番に従い、独自ルールで差を付けない。差を付けるのは手触りと演出の質と、ブラウザを開けばすぐ遊べること
- 明るく、軽く、すぐ始まる。起動から対戦まで数タップで、スマホでも PC でも同じ気持ちよさ

| 採る | 採らない |
|---|---|
| 連鎖の手応えを増す演出・音 | 人物の反応で感情を伝える演出 |
| 記録と対戦を続けたくなる仕組み（記録、リプレイ、対戦成績） | 課金・ガチャ・スタミナ |
| 初心者が連鎖に届くまでの導線（遊び方、パズル面） | 覚えることが増える独自ルール |
| 軽さを保つ実装（CSS の背景、決定論的な core） | 見た目のために重くなる実装 |
