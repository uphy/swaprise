# ゲームのルール

このジャンルの定番の挙動に合わせている。フレーム数や得点表は公開されている解析値を元にした。ロジックは `src/core/` にあり、60fps の固定 tick で進む決定論的シミュレーション。同じ seed と入力列なら同じ結果になる。

## 盤面と消去

- 6列×12段、下からせり上がる盤面。次にせり上がる行は暗く表示
- 横2マスのカーソルで隣接する2枚（またはパネルと空白）を入れ替える。入れ替えは4フレーム
- 同じ柄が縦横3枚以上で消える。消去中はせり上がりが止まる
- 同時消し（4枚以上）と連鎖。消去で落ちたパネルにだけ連鎖フラグが付く
- アクティブ連鎖。消去中・落下中も入れ替えを受け付ける
- 時間差連鎖。別々に着地した2組が「2, 3」と数えられる
- 得点表は公開されている解析値。3枚消しの13連鎖で累計9,170点、14連鎖以降のボーナスは0、31個消しは0点
- 手動せり上げは1段1点。停止表示中の最初の1段は0点
- 消去中も手動せり上げは可能。自動せり上がりは消去・停止時間中には進まず、天井接触中・着地の揺れ中・パズル・タイムアタックの時間切れ後は手動でも上げられない
- 天井に触れても消去中・変身中・落下中（落下前の猶予を含む）はゲームオーバーにならない。猶予を過ぎるとゲームオーバー

## タイミング

タイミングは `src/core/constants.ts` の `TIMING` にフレーム数でまとめてあり、手触りの調整はここを変える。消去の点滅・柄を見せる時間・1枚ずつ消える間隔・落下前の猶予は `clearTiming(level)` でスピードレベルに応じて短くなる（レベル1が最長、レベル50以上で最短）。

アクティブ連鎖を仕込みやすいよう、消去後の落下前には18フレーム（0.3秒、レベル50以上は8フレーム）の猶予がある。消去で落ちたパネルは着地後も12フレーム連鎖フラグを保持し、その間に交換を完了して揃えれば連鎖になる。落下先や周囲のパネルを動かして仕込めるが、落下中のパネルそのものは交換できない。

## 対戦

- 同時消し n個 で幅 n-1 の板、n連鎖で幅6・厚さ n-1 の板（上限12段）。8個以上は分離。連鎖の板は1つの連鎖につき1枚で、連鎖が終わってから最終連鎖数で送る（途中の段階では送らない）。同時消しとビックリパネルの板は揃ってから100フレーム待って送り、待っている間に別の同時消しがあれば合流して待ち直す。自分の連鎖中に待ちが明けた板は、連鎖が終わったときに連鎖の板と一緒に送る
- 送った板は52フレーム後に相手の予告に入り、相手の盤面が静止（入れ替え・浮遊・落下・消去・変身のどれもなく、連鎖フラグの付いたパネルもない状態が2フレーム続く）してから降る。消し続けている限り降らないので、連鎖や同時消しを繋いで粘れる。相殺（自分の攻撃で予告の板を打ち消す）は入れていない。粘りは「消し続けて降らせない」で表現する
- 予告は盤面の中の上端に出し、板ごとのバーの脇に段数の合計を出す。次の静止で降る板は橙に点滅し、その瞬間に一度だけ警告音が鳴る。届いた板は受けた盤面に「+N」で出す
- おじゃまパネルは隣接するパネルを消すと変身。厚さ1段の板（同時消し・2連鎖）は、いくつ積み重なっていても1度の消去で全部が通常パネルになる。3連鎖以上の厚い板は1度の消去で最下段の1段だけが通常パネルになり、残りはおじゃまのまま隣で消すたびに1段ずつ減る。変身の途中で全段が柄を見せてから上の段がおじゃまに戻る（見た目は「戻ったのに残った」ように見えるが仕様）。同じ種類で触れ合っている板は一緒に変身する
- おじゃまの解凍は下から上、各段は右から左に進む。通常パネルになる最下段の色を先に見せ、上段はおじゃまの姿を保つ。全マスのめくり演出後も45フレーム（0.75秒、レベル50以上は24フレーム）待ち、変換完了までは板をその場に留める。この間に周囲を入れ替えて連鎖を仕込める
- おじゃまは下に積まれたパネルと一緒に落ちて同じフレームに着地する。落ちたパネルが着地して揃えば、乗っていたおじゃまはその瞬間に隣接しているので変身する。おじゃまの上に乗ったパネルもおじゃまと一緒に落ちる
- 変身で出たパネルには連鎖フラグが付くので、おじゃま返しが成立する
- ビックリパネル（対戦専用の「！」付き灰色パネル）。12枚消すごとにせり上がり行へ1枚混ざり、1試合24枚まで。ビックリパネル同士が3枚以上揃うと「消した枚数−2」枚の灰色の板（幅6・厚さ1段）を送る。灰色のおじゃまと通常のおじゃまは同時に変身しないので、交互に積むとサンドイッチになる
- 結果の見出しは日本語設定でも WIN / LOSE / DRAW を使う

## モード

- **ENDLESS**: スピードレベルは消した枚数（10枚で1）と経過時間（8秒で1）の高い方で上がり、下がらない。時間でも上がるので、遅い人でも1回のプレイは8分ほどで終わる。上手い人は消去で先に上がる。この上がり方はパズル以外の全モードで同じ。上位5件のスコアを localStorage に保存する
- **TIME ATTACK**: 2分間で何点取れるか。時間内に天井へ届いたらそこで終わり。上位5件をエンドレスとは別に保存する。完走時は「時間切れ」の見出しを出さず、得点と最大連鎖・同時消し・連鎖の記録を大きく表示する。制限時間などを変更したプレイでも同じ戦績画面を使うが、オンライン順位の取得・送信は行わない
- **PUZZLE**: せり上がりのない面を、決められた手数（入れ替えの回数）で全部消す。6 ステージ × 10 面。入れ替えは盤面が静止しているときだけ受け付け、成功した入れ替えを1手と数える（空マスとの入れ替えも1手）。手数を使い切ってパネルが残ると失敗。開始のカウントダウンはない。UNDO で最後の手を戻し（失敗の結果からも戻せる）、REDO で戻した手を打ち直す。HINT は 1 回目で次の手の技法（横・縦・落として揃える・連鎖・同時消し・消えない準備）を文で出し、2 回目で入れ替えるマスを盤面に光らせる。ヒントは今の盤面を残り手数で解き直して出すので、解けない盤面では戻すよう案内する。戻してもヒントを見てもクリアは記録する。クリアした面は localStorage に記録する。面の作り方は [puzzles.md](puzzles.md)
- **LEARN**: 初心者向けの練習。せり上がりのない固定の盤面で、消す・落とす・連鎖・同時消し・アクティブ連鎖を 1 課 1 技法で身につけ、最後の課だけゆっくりせり上がる盤面で 2 連鎖を組む。手は縛らず、達成は起きたこと（消えた・連鎖数・同時消しの枚数・消去中の入れ替え）で判定する。動かす 2 マスは最初から光らせ（手を見つけるのは PUZZLE の役目）、アクティブ連鎖の課は最初の消去が始まった瞬間に次の目印を出す。届かない手で盤面が静止したら RESET で戻す案内を出す。この課だけ点滅と落下前の猶予を 2 倍にする。固定の面は RESET で戻せ、終えた課は localStorage に記録する。課の定義は `src/core/lessons.ts`
- **VS CPU**: EASY / NORMAL / HARD の CPU と対戦。勝敗数を保存する。スピードレベルはエンドレスと同じ規則で上がり、2つの盤面は高い方に揃える（多く消した側に合わせて両方が速くなる）。CPU は人と同じ制約（カーソルを1マスずつ動かし、カーソル位置でだけ入れ替える）で動く（`src/core/ai.ts`）
  - 手の探し方: 1回の入れ替えで揃う手に加え、横3つ・縦3つを目標にパネルを横へ運ぶ・穴に落とす手順を数手先まで読む。消去中は消えたあとの盤面を目標にして、落ちてくるパネルで揃う手順（アクティブ連鎖）を仕込む。おじゃまに隣接する消しと、消したあとに連鎖する消しを優先し、危険状態では連鎖より高い位置を早く崩す
  - 難易度の差: 読みの深さ（EASY 1手・NORMAL 2手・HARD 4手）、思考の待ち時間（EASY 100F・NORMAL 50F・HARD 20F）、カーソル速度（1マス 16F・10F・6F）、連鎖読みとアクティブ連鎖（HARD のみ）。手が見つからないときはどの難易度でも深く読み直すので、止まったままにはならない
- **2 PLAYERS**: 同じキーボードかゲームパッド2台での対戦。スピードレベルは VS CPU と同じ
- **ONLINE**: ログイン不要のオンライン対戦。表示名を入力し、友達へ招待URLを送るか、ランダムに相手を探す。招待では両者の準備完了、ランダムではマッチ成立後の3秒カウントダウンで始まる。両者が希望すれば再戦できる。勝敗は端末に通算し、相手別にも数える（相手の端末が初回に作る匿名 id を鍵にするので、相手が名前を変えても同じ相手として続く。結果画面と対戦中の状態行に「vs 名前 3W 1L」、選択画面に最近の相手 5 人を出す）。設計は [online-multiplayer.md](online-multiplayer.md)
  - 招待URLは最後の参加・退出・対戦から24時間有効。LEAVE ROOM は自分の席だけを空けるので、同じURLで入り直せる。両者が退出しても期限内なら再利用できる。期限切れはURLを開いた時点で表示する
  - 画面を閉じたりタブの復帰情報を失ったりしても、同じブラウザでONLINEを開くと参加中の部屋を確認できる。RESUME HEREでこの画面へ引き継ぐか、LEAVE AND CONTINUEで退出して別の部屋へ進める。別タブのランダム待機も解除できる
  - 退出は接続中のWebSocketに依存せず、サーバーの受付を確認する。通信に失敗してもRETRY、または次にONLINEを開いたときに再試行する。招待部屋の待機・結果画面で切断した席は60秒で解放し、招待URL自体は24時間維持する
  - 1試合は最大10分、時間切れは引き分け。設定中も対戦は進む。画面オフや切断では一時停止し、1人につき累計15秒以内なら復帰できる。戻らなければ切断負け、同期ずれやサーバー障害は無効試合
  - ランダム待機で 15 秒経っても相手が来なければ「今は誰も待っていません」と PLAY VS CPU を出す。押すと待機列から抜け、その端末だけで CPU（NORMAL）と対戦する。CPU を人に見せかけず、勝敗は VS CPU の記録にもオンラインの通算にも入れない。結果の FIND MATCH で選択画面を挟まずに待機へ戻る
  - FIND MATCHは接続前にも受付条件を確認する。旧版ならRELOAD、参加中なら復旧操作、日次上限ならリセット時刻を表示する
  - 無料枠内で運用するため、利用量に応じて受付を停止する。ランダム対戦を先に停止し、招待用の枠を残す。日次枠は日本時間9時に更新される

## 記録

- エンドレス・タイムアタックの上位5件、CPU 対戦の勝敗、オンライン対戦の勝敗、パズルのクリアは localStorage（`swaprise.highscores.v1`）に持つ。メニューの各項目の下に出し、RECORDS で一覧が開く
- 標準ルールのエンドレス・タイムアタックは、公開をオンにすると名前つきでサーバーに送り、モード別の上位50件と自分の順位を見られる。詳細は [online-scores.md](online-scores.md)
- エンドレス・タイムアタックの結果画面と記録には、得点・最大連鎖・同時消し・連鎖に加えて **1 手あたりの得点**（PTS / SWAP。得点 ÷ 成功した入れ替えの回数、小数 1 桁）を出す。少ない入れ替えで大きく消す（連鎖を組む）ほど上がり、考えずに動かし続けるほど下がる。得点表と順位の並び（得点降順）は変えない。入れ替えの回数を持たない古い記録（2026-09-18 より前の端末の記録・サーバーの記録）にはこの値を出さない
- 結果画面の SHARE で得点を共有できる（Web Share API。ない環境ではクリップボードにコピー）
